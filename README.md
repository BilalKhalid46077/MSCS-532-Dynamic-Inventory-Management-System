# Dynamic Inventory Management System Using Python

## Project Overview

This repository contains my course project for **Developing and Optimizing Data Structures for Real-World Applications Using Python**. The project focuses on designing, implementing, optimizing, and evaluating a **Dynamic Inventory Management System** using Python. The system demonstrates how data structures such as dictionaries (hash tables), lists, and queues can be used to efficiently manage inventory operations including adding products, updating quantities, searching products, displaying inventory, and processing restocking requests.

The project is organized into separate phases, with each phase building upon the previous one.

## Project Phases

### Phase 2 – Proof of Concept

* Implemented the core inventory management functionality.
* Demonstrated basic inventory operations using Python.
* Included testing, documentation, and a project report.

### Phase 3 – Optimization, Scaling, and Final Evaluation

* Optimized the data structures for improved performance.
* Added scalability testing using large datasets.
* Performed performance analysis and compared the optimized implementation with the proof of concept.
* Included the final report and updated documentation.
